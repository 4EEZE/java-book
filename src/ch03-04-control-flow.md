## Управление потоком выполнения

## Ветвления

Про `if` мы уже знаем главное: условие обязано быть `boolean`. Ветки `else if` и
`else` необязательны:

```java
void main() {
    int temperature = 15;

    if (temperature > 25) {
        IO.println("жарко");
    } else if (temperature > 10) {
        IO.println("нормально");
    } else {
        IO.println("холодно");
    }
}
```

```text
нормально
```

Фигурные скобки для однострочной ветки можно опустить, но не стоит. Классика
жанра — добавить в ветку без скобок вторую строку и получить код, который
выглядит как часть условия, а выполняется всегда:

```java,wrong_behavior
void main() {
    int temperature = 5;

    if (temperature > 25)
        IO.println("жарко");
        IO.println("надеть шорты");
}
```

```text
надеть шорты
```

Отступ говорит одно, компилятор понимает другое: в `if` попала только первая
строка. Ставьте скобки всегда — это ничего не стоит.

Когда обе ветки лишь вычисляют значение, короче написать тернарный оператор:

```java
void main() {
    int temperature = 15;
    String verdict = temperature > 20 ? "тепло" : "прохладно";
    IO.println(verdict);
}
```

```text
прохладно
```

## Выбор из многих вариантов: `switch`

Исторически `switch` в Java выглядел так:

```java,wrong_behavior
void main() {
    int day = 6;

    switch (day) {
        case 6:
            IO.println("суббота");
        case 7:
            IO.println("воскресенье");
        default:
            IO.println("рабочий день");
    }
}
```

```text
суббота
воскресенье
рабочий день
```

Программа напечатала три строки вместо одной. Это **проваливание**: выполнив
подходящую ветку, `switch` продолжает выполнять все следующие, пока не встретит
`break`. Поведение унаследовано из C, и подразумевает оно, что `break` вы
напишете сами:

```java
void main() {
    int day = 6;

    switch (day) {
        case 6:
            IO.println("суббота");
            break;
        case 7:
            IO.println("воскресенье");
            break;
        default:
            IO.println("рабочий день");
    }
}
```

```text
суббота
```

Забытый `break` — одна из самых долгоживущих ошибок в истории языка.

## `switch` как выражение

Начиная с Java 14 у `switch` есть вторая форма — со стрелкой:

```java
void main() {
    int day = 6;

    String name = switch (day) {
        case 6 -> "суббота";
        case 7 -> "воскресенье";
        default -> "рабочий день";
    };

    IO.println(name);
}
```

```text
суббота
```

Отличий три, и каждое устраняет отдельную проблему.

**Проваливания нет.** Выполняется ровно одна ветка, `break` не нужен и не
пишется.

**Это выражение.** У `switch` есть значение, которое можно присвоить или
вернуть. Обратите внимание на точку с запятой после закрывающей скобки — она
завершает инструкцию присваивания.

**Полнота проверяется.** Если возможен вариант, не покрытый ни одной веткой,
программа не соберётся:

```java,does_not_compile
void main() {
    int day = 6;
    String name = switch (day) {
        case 6 -> "суббота";
    };
}
```

```text
error: the switch expression does not cover all possible input values
    String name = switch (day) {
                  ^
```

Компилятор не даст забыть про остальные случаи. Со старой формой он молчал, а
переменная тихо оставалась неинициализированной.

Несколько значений в одной ветке перечисляются через запятую, а если ветке
нужно больше одной строки — она берётся в фигурные скобки и возвращает значение
через `yield`:

```java
void main() {
    int day = 6;

    String kind = switch (day) {
        case 6, 7 -> "выходной";
        default -> {
            String prefix = day + "-й";
            yield prefix + " рабочий день";
        }
    };

    IO.println(kind);
}
```

```text
выходной
```

> **Современный подход:** новую форму стоит использовать по умолчанию, а старую
> оставить для чтения чужого кода. Она короче, не требует `break`, проверяется
> на полноту и работает как выражение. Отдельно важно, что `switch` умеет
> ветвиться не только по числам и строкам, но и по типам — на этом построено
> сопоставление с образцом, которому посвящена [глава 7](ch07-00-records-and-patterns.md). Именно там новая форма
> раскрывается полностью.

## Циклы

**`while`** повторяет тело, пока условие истинно. Проверка выполняется до
начала итерации, поэтому тело может не выполниться ни разу:

```java
void main() {
    int count = 3;
    while (count > 0) {
        IO.println(count);
        count--;
    }
    IO.println("пуск");
}
```

```text
3
2
1
пуск
```

**`do`/`while`** проверяет условие после тела — значит, тело выполнится хотя бы
один раз. Нужен редко, но когда нужен, заменить его неудобно:

```java
void main() {
    int count = 0;
    do {
        IO.println("выполнено хотя бы раз");
    } while (count > 0);
}
```

```text
выполнено хотя бы раз
```

**`for`** собирает в одной строке три части: подготовку, условие продолжения и
шаг:

```java
void main() {
    for (int i = 0; i < 3; i++) {
        IO.println(i);
    }
}
```

```text
0
1
2
```

Переменная `i` существует только внутри цикла — снаружи её нет.

**`for` по элементам** перебирает массив или коллекцию, не требуя индекса:

```java
void main() {
    String[] names = {"Аня", "Борис", "Вера"};

    for (String name : names) {
        IO.println(name);
    }
}
```

```text
Аня
Борис
Вера
```

Читается как «для каждого `name` из `names`». Если индекс не нужен — а он чаще
не нужен, — используйте эту форму: в ней невозможно ошибиться с границами.

## `break` и `continue`

`break` прерывает цикл целиком, `continue` — только текущую итерацию. Обоими мы
пользовались в игре из второй главы:

```java
void main() {
    for (int i = 1; i <= 10; i++) {
        if (i % 2 == 0) {
            continue;
        }
        if (i > 7) {
            break;
        }
        IO.println(i);
    }
}
```

```text
1
3
5
7
```

Чётные пропускаются через `continue`, а на девятке срабатывает `break`.

Из вложенных циклов `break` выходит только из внутреннего. Чтобы выйти сразу из
обоих, цикл помечают меткой:

```java
void main() {
    outer:
    for (int i = 1; i <= 3; i++) {
        for (int j = 1; j <= 3; j++) {
            if (i * j > 4) {
                break outer;
            }
            IO.println(i + "×" + j + "=" + (i * j));
        }
    }
}
```

```text
1×1=1
1×2=2
1×3=3
2×1=2
2×2=4
```

Метка — это имя с двоеточием перед циклом. `break outer` прерывает помеченный
цикл, а не ближайший.

Пользоваться метками стоит редко. Если они понадобились, обычно это признак,
что вложенные циклы просятся в отдельный метод — из него можно просто сделать
`return`.
