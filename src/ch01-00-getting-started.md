# С чего начать

Начнём с самого начала. В этой главе мы:

- поставим JDK — комплект разработчика Java;
- напишем программу, которая печатает «Привет, мир!»;
- разберёмся, чем сборка проекта отличается от запуска одного файла, и когда
  она вообще нужна.

Глава короткая и почти целиком практическая: тут больше команд, чем рассуждений.

Два обещания, которые она даст и которые книга сдержит позже. Первое: мы начнём
с короткой формы записи программы, появившейся в Java 25, а на классическую
перейдём в главе 5 — там для этого обнаружится вполне техническая причина, а не
вопрос вкуса. Второе: сообщения компилятора мы будем читать целиком и сразу, с
первого же примера, потому что в Java это основной способ, которым язык с вами
разговаривает.

Если JDK у вас уже стоит и вы знаете, что такое Maven, — пролистайте до раздела
«Привет, мир!»: там есть кое-что, что изменилось в Java за последние пару лет и
о чём вы могли не слышать.
